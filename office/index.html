Opening the office…

The office is private to Joey and Steffen. Paste your GitHub key once on this phone or computer; it stays on this device. No key yet? The steps are just below.

No key yet? Make one in two minutes

Sign in to GitHub first, then follow the steps for your name. You only do this once per phone or computer.

Steffen

Make my key on GitHub
  1. The page opens with the name "Ube Ube Office" and the repo box already ticked. Leave them as they are.
  2. Expiration: pick No expiration (or 90 days if you'd rather redo it now and then).
  3. Scroll to the bottom and press Generate token.
  4. Copy the key it shows (it starts with ghp_). GitHub shows it only once.
  5. Come back here, paste it in the box above and press Open the office.

Joey

Make my key on GitHub
  1. Token name: Ube Ube Office. Expiration: the longest it offers, or a date you like.
  2. Repository access: Only select repositories, then pick ube-ube-city-app.
  3. Permissions: open Repository permissions, find Contents and set it to Read and write.
  4. Press Generate token at the bottom and copy the key (it starts with github_pat_). GitHub shows it only once.
  5. Come back here, paste it in the box above and press Open the office.

Why two kinds: the office lives in Joey's private repo. Joey owns it, so her key can be limited to just that repo; Steffen is invited to it, and GitHub only lets an invited person use the "classic" kind. The key stays on this device and is only ever sent to GitHub. To use the office on another phone, make it there the same way, or copy the same key over.
